# Scope of this preview

This page lists what the public preview covers and what it does not. A
claim outside the "Covered" list is not made by this package.

## Covered

| Item | Covered in this preview |
|---|---|
| Nodes | B00 through B69 in `data/nodes.json` order: 71 of the 73 nodes (L99 sits between B38 and B39 and is included) |
| Compared exits | 77 per sample. Six nodes (B00, B04, B08, B14, B22, B30) expose two compared outputs each |
| Samples | 2 published samples: `sample-1-reference` (`c1-C-img-full`) and `sample-3-procedural-scene` (`d23-n2-nat320x240`) |
| Total compared outputs | 154 (77 × 2), all byte-identical to the reference; hashes in `reference/reference_hashes.json` |
| Resolution | 320×240 |
| Frame | a single frame after reset (no temporal history) |
| Weights | the `WEIGHTS_HT` resource with sha256 `836f445d…`; `tools/extract_weights.py` refuses any other |
| Reference | outputs of the native runtime (DLL 310.8.0.0, sha256 `e16bcf15…`) captured on an NVIDIA GeForce RTX 5090 D (sm_120); full identity in the header of `reference/reference_hashes.json` |
| Execution | CPU only, single-threaded; no GPU and no DLL loading at run time |

154 compared outputs are not 154 graph nodes; see the "Compared exits" row.

## Not covered

- **B70 and S157, and therefore the final image.** See
  [`B70_S157_STATUS.md`](B70_S157_STATUS.md).
- **Arbitrary user input.** Only the two published samples' colour inputs,
  generated by `tools/make_inputs.py`, are covered. The node
  implementations were developed and debugged against these samples; the
  preview makes no claim that another image would also match.
- **Other resolutions, temporal (multi-frame) operation, and other runtime
  or weight versions.**
- **The project's second sample** (`c1-C-b1-full`), which is not published;
  see [`SAMPLE_NAMES.md`](SAMPLE_NAMES.md).
- **Environments other than the one documented** in
  [`REPRODUCIBILITY.md`](REPRODUCIBILITY.md). Other environments may work
  but are not part of the current claim.
- **Performance.** This is a correctness reference, not a real-time
  replacement; a full two-sample run takes tens of minutes on CPU.
- **Uniform audit depth.** Not every code path has been audited to the same
  depth; the claim is about the output bytes listed above.
